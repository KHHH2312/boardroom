# Third-party components

Boardroom has no runtime npm dependencies and no build step. It uses vanilla browser APIs and
Node's built-in `http`, `fs` and `crypto` modules.

Typefaces are system families (Bahnschrift/Segoe UI/Consolas). No fonts, icon packs or CDN assets
are bundled.

Boardroom is not affiliated with Excalidraw or tldraw.
