# Changelog

## 1.7.0 — 2026-10-30

- Board templates: Retrospective, Kanban and Wireframe start a populated, editable plan.
- Browser golden path grows to 26 checks.

## 1.6.0 — 2026-10-30

- Keyboard shortcuts sheet on ? or the KEYS button.
- Browser golden path grows to 24 checks.

## 1.5.0 — 2026-10-30

- 32-unit grid snapping for new marks, moves and resizes; toggle in the status bar or press G.
- Browser golden path grows to 22 checks.

## 1.4.0 — 2026-10-30

- Search the board library by name; match count, no-match state, Escape to clear, Enter to open.
- Browser golden path grows to 20 checks.

## 1.3.0 — 2026-10-30

- Shift-click Export PNG to crop the file to the selected marks.
- Browser golden path grows to 17 checks.

## 1.2.0 — 2026-10-30

- Paste an image from the clipboard or drop a file on the stage, not just the toolbar picker.
- All image paths share one validated placement routine and stay undoable.
- Browser golden path grows to 16 checks.

## 1.1.0 — 2026-10-30

- Place PNG, JPEG and WebP images on a plan; move, resize and layer them like any mark.
- Images are read locally, validated in the picker and the model, and stored inline in the board JSON.
- Model/server suite grows to 47 checks; the browser golden path grows to 14.

## 1.0.0 — 2026-10-30

- First public release of Boardroom.
